## About YukkitMC

We believe Minecraft is at its best when the tools around it stay out of your way.

**YukkitMC** is an independent development organization building mods and utilities for **Minecraft: Java Edition**, with a special focus on multiplayer quality of life. From simple interface improvements to powerful client-side tools, our goal is to solve real problems without making the game unnecessarily complicated.

We care about useful features, thoughtful design, clean code, and reliable performance.

## What we're building

| Area | Our focus |
| :-- | :-- |
| **Quality of life** | Small improvements that make everyday gameplay easier. |
| **World utilities** | Tools for exploring, organizing, and working with world data. |
| **Interface & accessibility** | Clearer information, better controls, and more comfortable interactions. |
| **Performance** | Lightweight features with minimal overhead. |
| **Developer tools** | Practical utilities for testing, debugging, and mod development. |

> Our projects are developed and released individually. Features, supported Minecraft versions, mod loaders, and availability will be documented in each repository.

## Our approach

- **Player-first.** Build features that solve actual problems.
- **Simple by design.** Powerful tools should still be easy to use.
- **Performance matters.** Avoid unnecessary complexity and resource usage.
- **Transparent development.** Document behavior, limitations, and changes clearly.
- **Respect multiplayer communities.** Server rules and other players matter.

## Contributing

Ideas, bug reports, documentation improvements, and code contributions are welcome wherever a repository accepts them.

1. Find a project that interests you.
2. Read its README and contribution guidelines, if available.
3. Check existing issues before reporting a bug or suggesting a feature.
4. Open a focused issue or pull request with enough detail to review.

Please follow each project's license and contribution requirements.

## A note on multiplayer

YukkitMC creates tools to improve the player experience, not to guarantee an advantage or bypass server policies. Whether a particular mod is allowed depends on the server and its rules. Always check those rules before using client-side modifications.
