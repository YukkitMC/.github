## About

YukkitMC is an independent organization building reliable client-side mods and utilities for **Minecraft: Java Edition**. We focus on clean code, low overhead and clear documentation.

## Featured project

### [Yukkit Toolkit](https://github.com/YukkitMC/yukkit-toolkit)

Modular, client-side utilities for Fabric, controlled from a single in-game panel.

| Module | Description |
| :-- | :-- |
| **ClickGUI** | Configurable control panel (Right Shift) |
| **Freecam** | Independent camera movement |
| **Fullbright** | Brightness override |
| **Time & Weather** | Client-side day cycle and weather |
| **World Downloader** | Experimental local capture of loaded chunks |

> `v0.1.0-alpha.3` · Experimental build. Expect bugs and breaking changes.
